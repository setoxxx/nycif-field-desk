## Primary category selection

Choose the most specific category that matches the story.

### Civic Watch

Use for:

- public filings
- public hearings
- agency calendars
- agency rulemakings
- contracts
- procurement
- land use
- zoning
- public records
- local government accountability

### Public Safety Watch

Use for:

- public safety datasets
- precinct/civic context
- agency-response questions
- public meetings connected to safety

Do not use for fear-based or police-blotter framing.

### Street Permit Watch

Use for:

- street openings
- lane/sidewalk closures
- utility work
- street permits
- curb/public-space disruption
- street-level infrastructure impacts

### news

Use for general reporting that does not fit a watch category.

### Week Events / Weekend Events

Use for event guides and curated public happenings.

## Tag strategy

Use 5 to 10 tags per article.

Recommended tag mix:

1. Site tag: `NYC In Focus`
2. Borough tag: `Brooklyn`, `Queens`, `Manhattan`, `Bronx`, `Staten Island`
3. Neighborhood tag if central
4. Topic tag: `public records`, `NYC land use`, `NYC contracts`, `NYC parks`, `public hearings`
5. Agency/entity tag if central: `DSNY`, `DOHMH`, `City Planning Commission`
6. Project/person/event tag only if central

## Tags to avoid stacking together

Avoid using multiple near-duplicate tags in the same post unless there is a specific reason.

Examples:

```text
NYC
NewYorkCity
NYCevents
NYC Events
free NYC events
NYC free events
free events NYC
```

Pick the cleanest tag for that story.

## New tag creation rule

Create a new tag only when:

- it will likely be reused
- it names a central agency, place, project, person, law, hearing, or recurring topic
- it improves discoverability

Do not create a one-off tag for every minor phrase in the story.
